# 📊 Customer Churn Prediction System

An end-to-end Machine Learning project that predicts whether a telecom customer is likely to churn using a trained Random Forest model and an interactive Streamlit dashboard.

---

## 🚀 Project Overview

Customer churn is one of the biggest challenges faced by telecom companies. This project helps identify customers who are likely to leave the company so that retention strategies can be planned in advance.

The complete machine learning pipeline includes:

- Data Understanding
- Data Cleaning
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Model Training
- Pipeline Creation
- Streamlit Deployment

---

## 📂 Dataset

**Dataset:** Telco Customer Churn Dataset

- Total Customers: **7043**
- Features: **19**
- Target Variable: **Churn (Yes/No)**

## 🤖 Machine Learning Models

The following models were trained and evaluated:

- Logistic Regression
- Decision Tree Classifier
- Random Forest Classifier ✅ (Final Model)

Random Forest was selected because it achieved the best overall performance on the dataset.

## ▶️ Run the Project

Clone the repository

```bash
git clone https://github.com/sehajdeep-dot/Customer-Churn-Prediction.git
```

Move into project directory

```bash
cd Customer-Churn-Prediction
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run Streamlit

```bash
streamlit run app.py
```
